Android SSH · 远程管理 · 文件同步

春夏秋手机安全助手

把 Android 设备变成一台可通过标准 SSH 访问的小主机：在应用内运行完整 sshd，并提供 rsync、sftp/scp 文件传输，以及内网穿透、Tailscale 组网与远程运维能力。

核心能力

SSH 服务

基于 Dropbear 的 sshd，可配置端口（默认 2222）、监听接口与登录方式。

文件传输

rsync / sftp / scp，由 OpenSSH sftp-server 提供；无需额外守护进程。

提权模式

应用权限 / Root（su）/ ADB（无线调试）三种运行身份。

内置终端

在应用内以不同权限执行命令并实时查看输出。

内网穿透

托管官方 frpc，把本机 sshd 端口映射到公网 frps。

Tailscale 组网

托管官方 tailscaled，加入你自己的 tailnet。

哪吒监控

托管官方 nezha-agent，向面板汇报设备状态。

远程桌面

屏幕共享与可选触控控制（仅限可信私有网络）。

安全警告：远程桌面等 HTTP 服务没有认证和 TLS，只能在可信的私有网络中使用，禁止直接暴露到公网。Root / ADB 权限与端口映射会显著扩大操作影响范围；请只授权可信密钥并确认网络边界。使用前请阅读 安全说明与免责声明。

快速连接

在同一可信局域网内，用任意标准 SSH 客户端连接：

ssh -p 2222 your-user@phone-ip

# 文件备份（经由 SSH）
rsync -avP -e "ssh -p 2222" ./photos/ user@192.168.1.100:/sdcard/backup/photos/

# 上传单个文件
scp -P 2222 ./file.txt user@192.168.1.100:/sdcard/
